# Поиск маршрутов Московского метро

JavaFX приложение для поиска маршрутов в системе Московского метрополитена.

## Требования

- Java 23 или новее
- Maven 3.6 или новее

## Сборка приложения

Для сборки приложения выполните следующую команду:

```
mvn clean package
```

Это создаст JAR-файл в директории `target`.

## Запуск приложения

Существует несколько способов запуска приложения:

### Использование batch-файла (Windows)

Самый простой способ запустить приложение в Windows - использовать предоставленный batch-файл:

```
run.bat
```

### Использование Maven

Вы также можете запустить приложение с помощью Maven:

```
mvn javafx:run
```

или

```
mvn exec:java
```

### Использование Java напрямую

Если вы хотите запустить приложение напрямую с помощью Java, вам нужно указать путь к модулям и добавить необходимые модули JavaFX:

```
java --module-path "target\modules" --add-modules javafx.controls,javafx.fxml,javafx.graphics -jar target\FinalLab_18.05.2025-1.0-SNAPSHOT.jar
```

## Устранение неполадок

Если вы столкнулись с ошибкой "Module javafx.graphics not found, required by FinalLab", убедитесь, что вы запускаете приложение с правильным путем к модулям. Batch-файл или команды Maven должны автоматически обрабатывать это за вас.

## Функциональность

- Поиск маршрутов между любыми двумя станциями Московского метро
- Отображение подробной информации о маршруте, включая пересадки и время в пути
- Интерактивная карта метро с цветными линиями
- Выбор станций как из выпадающего списка с поиском, так и нажатием на карте
- Три варианта маршрута: самый быстрый по количеству станций, самый быстрый по времени и с минимальным количеством пересадок
- Отображение детальной информации о пересадках в маршруте
